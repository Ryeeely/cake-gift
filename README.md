# 🎂 心意蛋糕工坊 (Cake Gift)

> 一个基于 Three.js 的 3D 交互式蛋糕定制与礼物分享工具。

## 📖 项目简介

这是一个“礼物”主题的期末大作业。用户可以通过上传照片为 3D 蛋糕提取配色方案，也能通过分享礼物文件，让朋友看到一模一样的定制蛋糕。

**核心流程：**

1. **送出礼物**：上传照片 → 自动提取配色 → 手动微调部件颜色 → 导出 `cake_gift.json` 礼物文件。
2. **收到礼物**：导入 `cake_gift.json` → 完成三道“烹饪”互动问答 → 长按点亮蜡烛 → 查看专属蛋糕与祝福语。

## 🚀 如何运行

### 方法一：本地运行（推荐）

1. 克隆或下载本仓库代码。
2. 确保 `index.html` 和 `model.glb` 在**同一目录**下。
3. 使用本地服务器运行（**不要**直接双击打开 HTML，否则可能因跨域问题无法加载模型）：
   - **Python 3**：在终端进入项目目录，运行 `python -m http.server 8080`，然后访问 `http://localhost:8080`。
   - **Node.js**：运行 `npx http-server`，然后访问提示的本地地址。
4. 在浏览器中打开显示的地址即可开始使用。

### 方法二：在线预览（GitHub Pages）

访问：https://ryeeely.github.io/cake-gift/

> 注意：GitHub Pages 有时加载 `.glb` 模型文件可能较慢，请耐心等待。

## 📦 依赖与配置

### 依赖项

本项目为纯前端应用，无需额外安装包，所有依赖通过 CDN 引入：

| 依赖 | 用途 | 引入方式 |
|------|------|----------|
| [Three.js](https://threejs.org/) | 3D 场景渲染与模型加载 | CDN (`unpkg.com/three@0.128.0`) |
| [ColorThief](https://lokeshdhakar.com/projects/colorthief/) | 从照片中提取主色调 | CDN (`cdn.jsdelivr.net/npm/colorthief`) |

### 配置文件

无需额外配置文件。所有可调参数（灯光强度、相机位置、粒子数量等）均内置于 `index.html` 的 JavaScript 中，可按需修改。


## ✨ 主要功能

- **📸 照片取色**：上传任意照片，自动提取 5-8 种主色并应用到蛋糕各部件。
- **🎨 分部件上色**：支持对奶油、蛋糕胚、底座、淋面、巧克力、饼干、水果顶等部件独立调色。
- **✨ 环境光自定义**：自由调节蛋糕周围的氛围光颜色。
- **🎁 礼物分享**：导出包含配色、寄语、环境色的 `cake_gift.json` 文件，对方导入后即可看到完全一致的蛋糕。
- **🕯️ 长按点亮蜡烛**：完成三道烹饪问答后，长按蜡烛进入品鉴环节，增强仪式感。
- **🌟 动态粒子与星星**：蛋糕周围环绕流动粒子与旋转星芒，氛围感十足。

## 🛠️ 技术栈

- **Three.js**：3D 渲染引擎
- **GLTFLoader**：加载 `.glb` 模型文件
- **ColorThief**：图像主色提取
- **原生 JavaScript**：所有交互逻辑与 UI 控制
